## 部分练习说明

**通讯录**（day05 → day07 逐步升级）
- v1：用字典存「姓名 → 电话」，支持增删改查
- v2：加上 JSON 文件读写，数据能存下来，重新打开还在

**单词统计**（day05）
- 读入一句话，统计每个词出现几次——字典最经典的用法

**调接口**（day08）
- 用 `requests` 调用「一言」接口，取回一句随机的话并格式化输出
- 过程中发现接口有 CDN 缓存，通过加时间戳参数解决
