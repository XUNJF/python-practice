# 杭州 AI 岗位分析（22 份 JD）

> 对比之前那 20 份成都 JD。**结论：杭州的门槛更高、方向更偏 Agent，但对「有项目的人」更友好。**

| | 成都 | 杭州 |

## 二、⚠️ 跟成都最大的三个差异

### ① Agent 比 RAG 更突出

成都的 JD 里 RAG 是最高频词。**杭州这里，Agent 出现了 18 次以上**，还有专门的「Agent 开发工程师」岗位。

**而且要求很具体：**

- 任务规划（Planning）
- 工具调用（Tool Use）
- 状态管理（State）
- 长期记忆（Memory）
- 多智能体协作（Multi-Agent）
- 反思纠错循环

**这不是「听说过 Agent」就行的层次——要能说清楚每个模块怎么实现。**

### ② 明确要求「AI Coding 工具」

**这条很有意思，之前成都那批 JD 里几乎没有：**

> AI 编程工具重度玩家：Cursor、Claude code 等 AI 编程工具重度或顶级玩家，具备极强的 Prompt 编写与调优能力

**至少有 5 个岗位明确提了这一条。**

**意思是：你平时怎么用 AI 写代码，本身就是一项被考核的技能。**

### ③ 要求更「全栈」

杭州的岗位普遍要求你能**独立完成从需求到上线**：

- 前端（React/Vue 至少了解）
- 后端（FastAPI/Flask/Django）
- 部署（Docker、Linux）
- 数据库（MySQL、Redis、MongoDB）

**成都那批更偏「写好一个模块」，杭州更偏「你能独立交付一个东西」。**

## 四、三个对你特别重要的发现

### ① 你已经在积累一项被明码标价的技能

**「AI 编程工具重度玩家」这句话，你其实已经符合一半了。**

你这两周怎么学的？**用 Claude 讲概念、改代码、定位 bug、做实验。** 这本身就是「用 AI 编程工具完成实际交付」。

**面试时这是能讲的**：不是「我会用 ChatGPT 聊天」，而是「我这两周用 AI 工具从零写出了 FastAPI 服务 + 前端页面，整个过程是这样的……」

**只是你还没意识到这件事值得写进简历。**

### ② 项目要求比成都更硬

成都那批写「有项目经验者优先」。**杭州这里写得更具体：**

> 有完整 Agent 项目、实习或个人作品者
> 有可展示的项目 / 实习成果者优先
> 在 GitHub 上有高质量 AI 项目

**「可展示」是关键词——不是一个仓库，是一个能打开看、能讲清楚的东西。**

### ③ 应届身份：大部分友好，但要注意

- **写「在校/应届」「经验不限」** → 你能投
- **写「2027 届校招」** → 你不符合（你是 2026 届）
- **有一个明确写「可以接受应届生无经验，空档两年内，应届生转码（毕业 2 年内皆可），有老师带教」** → 这类最友好

**投递时先看毕业年份要求，别浪费简历。**

## 五、学习计划要补什么

### 按优先级排（结合 JD 频率 + 你现在的缺口）

| 优先级 | 内容 | 为什么 | 大概时间 |
|---|---|---|---|
| **1** | **RAG**（向量、embedding、Chroma） | 16+ 次，你已在计划里 | 1 周 |
| **2** | **工具调用 / Function Calling** | 9+ 次，Agent 的基础 | 3-4 天 |
| **3** | **Agent 核心概念**（规划、记忆、状态） | 18+ 次，杭州的核心 | 1 周 |
| **4** | **LangChain / LangGraph** | 14+ 次，最热框架 | 4-5 天 |
| **5** | **Docker + Linux 命令** | 10+ 次，工程必备 | 1 周 |
| **6** | **异步编程 asyncio** | 你的 Python 缺口 | 2-3 天 |
| **7** | **数据库**（MySQL / PostgreSQL 基础） | 8+ 次 | 4-5 天 |
| **8** | **MCP** | 6+ 次，概念不复杂 | 2-3 天 |

### 优先级低但知道有这回事

- **前端框架**（React/Vue）—— 杭州有 3 个岗位提，但不是硬要求
- **vLLM / Ollama** —— 推理部署相关，偏运维
- **微调 SFT / LoRA** —— 部分岗位提，但门槛高
- **评测体系 / 可观测性** —— Agent 工程化的进阶内容

### 明确跳过

- **ACM/ICPC、顶会论文** —— 华为那个 30-60K 的岗位要求的，那是算法研究岗，不是你的方向
- **强化学习、多模态、昇腾芯片** —— 算法岗内容

     → LangChain / LangGraph（4-5天）

**大约 6-7 周。加上你已有的基础，到明年 1-2 月是来得及的。**

## 七、一句话总结

**杭州比成都难，但方向没变——还是「Python + RAG + Agent」。**

**差别在于：成都要求你「会用」，杭州要求你「能讲清楚为什么」。**

**而这个差别，是靠「自己动手做过一遍」补上的，不是靠背概念。**
