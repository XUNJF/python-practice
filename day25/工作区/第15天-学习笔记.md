## 一、问题：每次回答都覆盖

```javascript
document.getElementById("answer").textContent = data.answer;
```

**`=` 是赋值，也就是「替换」。** 所以问三次，页面上永远只有最后一条。

---

## 二、⭐ 关键转变：从「改元素」到「造元素」

**之前写的 HTML 都是写死在文件里的：**

```html
<input id="question">
<button onclick="send()">发送</button>
```

**它们是固定存在的元素**——页面一打开就在那儿，你只能**改内容**。

**但对话记录的数量不确定**——问一次多一条，问十次十条，**没法预先写死**。

**所以要「动态生成」：需要的时候现场造。**

| | 写死的 HTML | 动态生成 |
|---|---|---|
| 什么时候存在 | 页面打开就有 | **需要时才造** |
| 有几个 | 固定的 | **看用户问了几次** |
| 例子 | 输入框、按钮 | **每一轮对话** |

## 三、三个操作（固定搭配）

### ① 造

```javascript
const div = document.createElement("div");
```

**`document.createElement("标签名")`** —— 造一个新元素。

⚠️ **造完还不在页面上**，只存在于内存里。**像捏好了泥人还没粘上去。**

### ② 填

```javascript
div.textContent = "内容";
```

### ③ 挂

```javascript
document.getElementById("chat").appendChild(div);
```

**`父元素.appendChild(子元素)`** —— 把它追加到末尾。

**顺序永远是：造 → 填 → 挂。**

---

## 四、`<div>` 是什么

**一个看不见的盒子。**

它本身不显示任何东西，**只用来把别的元素装在一起**。

```html
<div id="chat"></div>
```

**这个空盒子就是留给对话记录的地方**——每来一轮问答，就往里塞一个新的 `<div>`。

---

## 五、`textContent` vs `innerHTML`

| | 管什么 | 用来 |
|---|---|---|
| `textContent` | **纯文字** | 设置一段文字 |
| `innerHTML` | **里面所有的元素** | 清空一个有内容的容器 |

**清空对话列表要用 `innerHTML`**，因为里面装的是一堆元素，不是一段文字。

```javascript
document.getElementById("chat").innerHTML = "";    // 清空整个列表
document.getElementById("chat").textContent = "";   // 这只清掉文字，元素还在
```

**同理，取内容也有区别：**

```javascript
element.textContent    // 只要文字
element.innerHTML      // 连 HTML 标签一起
```

## 六、完整代码

```html
<!DOCTYPE html>
<html lang="zh">
<head>
    <meta charset="UTF-8">
    <title>我的AI助手</title>
</head>
<body>
<h1>我的AI助手</h1>

<input id="question" placeholder="输入你的问题"
       onkeydown="if(event.key==='Enter') send()">
<button onclick="send()">发送</button>
<button onclick="clearAll()">清空</button>

<div id="chat"></div>

<script>
    function addMessage(role, text){
        const div = document.createElement("div");
        div.textContent = role + ":" + text;
        document.getElementById("chat").appendChild(div);
    }

    async function send(){
        const q = document.getElementById("question").value;
        addMessage("你", q);

        const r = await fetch("/chat?question=" + encodeURIComponent(q), {method:"POST"});
        const data = await r.json();

        addMessage("AI", data.answer);
        document.getElementById("question").value = "";
        window.scrollTo(0, document.body.scrollHeight);
    }

    function clearAll(){
        document.getElementById("question").value = "";
        document.getElementById("chat").innerHTML = "";
    }
</script>
</body>
</html>
```

## 七、回车发送

```html
<input id="question" onkeydown="if(event.key==='Enter') send()">
```

| 部分 | 意思 |
|---|---|
| `onkeydown` | **按键按下时**（对应 `onclick` 是「点击时」） |
| `event.key` | 按的是哪个键 |
| `=== 'Enter'` | 是回车键 |
| `send()` | 就发送 |

**`event` 是浏览器自动传进来的**——里面装着这次按键的信息。

### ⚠️ `===` 是三个等号

JS 里推荐用**三个等号**比较：

| 写法 | 行为 |
|---|---|
| `==` | 只比值，会自动转换类型（`1 == "1"` 是 true） |
| `===` | **值和类型都要一样**（`1 === "1"` 是 false） |

**用 `===` 更安全**——避免「看起来相等其实类型不同」的坑。

（Python 里只有 `==`，没有这个问题。）

---

## 八、自动滚到底部

```javascript
window.scrollTo(0, document.body.scrollHeight);
```

| 部分 | 意思 |
|---|---|
| `window.scrollTo(x, y)` | 把页面滚到指定位置 |
| `document.body.scrollHeight` | **整个页面的高度**（包括看不见的部分） |
| `0, ...` | 横向不滚，纵向到底 |

**要放在 `send()` 的最后**——等 AI 的回答显示出来再滚。

## 九、一个真实的 bug（值得记）

改完 `id="answer"` → `id="chat"` 之后，`clearAll` 里忘了同步改：

```javascript
document.getElementById("answer").textContent = "";    // ← 还是 answer
```

**`getElementById("answer")` 找不到元素，返回 `null`**，然后 `null.textContent` 直接报错。

### 症状

**点「清空」，输入框清了，但对话列表没清**——而且**页面上一点提示都没有。**

### 怎么找到的

**按 F12 看控制台。** 那里有一行红色的：

```
Uncaught TypeError: Cannot set properties of null (setting 'textContent')
```

### 教训

**JavaScript 的报错，页面上是看不见的。**

| | 报错在哪 |
|---|---|
| Python | 终端里，一眼看到 |
| **JavaScript** | **浏览器控制台（F12）** |

**网页「点了没反应」，第一件事就是 F12。**

## 十、变量名和 id 的对应关系

**最容易出错的地方：`id` 改了，引用没改。**

```javascript
document.getElementById("chat")     // ← 这里的字符串
                                 ↑
                          必须是 HTML 里某个元素的 id
```

**改 `id` 的时候，记得全局搜一下还有哪里引用了它。**

（VS Code 里 `Ctrl+Shift+F` 全局搜索。）

**然后试试给「你」和「AI」的 `<div>` 加不同的背景色：**

```javascript
function addMessage(role, text){
    const div = document.createElement("div");
    div.textContent = role + ":" + text;
    if (role === "你") {
        div.style.background = "#e3f2fd";
    } else {
        div.style.background = "#f5f5f5";
    }
    document.getElementById("chat").appendChild(div);
}
```

**`div.style.background = "颜色"`** —— 用 JavaScript 直接改元素的样式。

**这是「动态生成」的另一个好处**：**每个元素可以长得不一样**，而写死的 HTML 都是一样的。
