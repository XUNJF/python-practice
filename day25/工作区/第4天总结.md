# 第 4 天总结 · 列表与字典

1. **列表（list）是按位置存放的有序容器**，用 `[]` 定义，什么类型都能放。索引从 **0** 开始，负数表示从后往前数（`[-1]` 是最后一个）；越界会报 `IndexError`。

2. **列表的核心操作**：增 `append` / `insert`，删 `remove` / `del` / `pop`，改直接赋值 `fruits[0] = "葡萄"`，查用 `len` / `in` / `index`，排序用 `sort()`（改原列表）或 `sorted()`（返回新列表）。切片 `[开始:结束]` 含头不含尾。

3. **遍历列表**：只要元素用 `for x in list`；同时要索引推荐用 `for i, x in enumerate(list)`，比 `range(len())` 更简洁。内置函数 `sum` / `max` / `min` / `len` 很常用。

4. **字典（dict）是按「名字」查找的容器**，用 `{键: 值}` 定义。取值优先用 `person.get("键", 默认值)` 避免 `KeyError`；增改写法相同（有就改，没有就加）；遍历常用 `for k, v in person.items()`。

5. **「列表套字典」是真实数据最常见的形式**（如接口返回的数据），配合 `for` 循环可以逐条处理、找最大值等。注意 f-string 内层字典取值要用**单引号**，避免引号冲突。常见报错要会认：`IndexError`、`KeyError`、`AttributeError`、`TypeError`。
