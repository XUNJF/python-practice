# 第 5 天学习笔记 · 字典（dict）

> 列表按「位置」找东西，字典按「名字」找东西。
> 现实里大部分数据是「有名字」的，所以字典比列表更常用。

---

## 一、基本语法

```python
person = {
    "name": "张三",
    "age": 25,
    "city": "成都"
}
```

花括号 `{}`，每项是 `键: 值`，逗号隔开。

```python
empty = {}                    # 空字典
```

**键**一般是字符串，**值**可以是任何类型——数字、字符串、列表、甚至另一个字典。

---

## 二、取值：`[]` vs `get()`

```python
person["name"]        # 张三 ✓

person["gender"]      # ❌ KeyError: 'gender'  ← 键不存在就崩
person.get("gender")            # None          ← 安全
person.get("gender", "未知")     # 未知          ← 安全，还能给默认值
```

**推荐用 `get()`。** 处理外部数据（接口返回、用户输入）时，你常常不确定某个键在不在。用 `[]` 程序会崩，用 `get()` 不会。

**`None` 是什么**：Python 里表示「什么都没有」的特殊值。可以这样判断：

```python
if person.get("gender") is None:
    print("没填性别")
```

---

## 三、增、改、删

**增加和修改写法一样**——有就改，没有就加：

```python
person["city"] = "重庆"        # city 已存在 → 修改
person["job"] = "工程师"       # job 不存在 → 新增
```

**删除：**

```python
del person["job"]              # 直接删
person.pop("age")              # 也是删，但会把删掉的值返回给你

value = person.pop("age")      # 可以接住它
```

---

## 四、遍历

```python
person = {"name": "张三", "age": 25, "city": "成都"}

# 只要键
for key in person:
    print(key)

# 只要值
for value in person.values():
    print(value)

# 键和值都要（最常用）
for key, value in person.items():
    print(f"{key}: {value}")
```

⚠️ **`items()` 不能省。** 写 `for k, v in person:` 会报错——Python 不知道你要拆成两个。

---

## 五、常用查询

```python
"name" in person         # True   判断「键」在不在（不是值！）
len(person)              # 3      有几组键值对
person.keys()            # 所有键
person.values()          # 所有值
person.items()           # 所有键值对
```

## 六、重点：列表套字典

**这是真实数据最常见的形态。** 从接口拿回来的数据、数据库查出来的结果，基本都是这个样子：

```python
students = [
    {"name": "张三", "score": 85},
    {"name": "李四", "score": 92},
    {"name": "王五", "score": 78},
]

# 遍历，取出每个人的信息
for stu in students:
    print(f"{stu['name']} 考了 {stu['score']} 分")

# 找出最高分的人
best = students[0]
for stu in students:
    if stu["score"] > best["score"]:
        best = stu
print(f"最高分是 {best['name']}，{best['score']} 分")
```

⚠️ **注意引号冲突**：`f"{stu['name']}"` 里面要用**单引号**，因为外层 f-string 已经用了双引号。混用会报语法错误。

---

## 七、字典套字典

也会遇到，比如按班级分组：

```python
classes = {
    "一班": {"人数": 30, "平均分": 85},
    "二班": {"人数": 28, "平均分": 88},
}

print(classes["一班"]["平均分"])      # 85
```

取值就一层一层往下写。

---

## 八、`in` 和 `get()` 该用哪个

两个都能处理「键不存在」，但场景不同：

```python
# 场景一：只想知道在不在
if "name" in person:
    print("有这个键")

# 场景二：要取值，且接受默认值
name = person.get("name", "匿名")

# 场景三：要取值，且必须要到（缺了就说明程序有问题）
name = person["name"]      # 让它崩，早点暴露问题
```

## 练习 1：单词统计（字典最经典的应用）

统计一句话里每个词出现了几次。

```
请输入一句话：the cat and the dog and the bird

the: 3
cat: 1
and: 2
dog: 1
bird: 1
```

**思路提示**：
1. `input().split()` → 得到单词列表（`split()` 默认按空格切）
2. `counts = {}` 建空字典
3. 遍历单词列表，判断这个词是不是**第一次见**：
   - 是 → 设为 1
   - 不是 → 在原来的基础上加 1

**这个练习直接对应后面 RAG 里的文本处理**，不是白练的。

用字典存「姓名 → 电话」：

```
1. 查看全部

3. 查找联系人
4. 删除联系人
```

结构和购物清单一样，但存储从列表换成字典。

**体会一下差别**：

## 常见报错

| 报错 | 原因 | 怎么修 |
|---|---|---|
| `KeyError` | 键不存在 | 用 `.get()`，或先 `in` 判断 |
| `ValueError: too many values to unpack` | 遍历字典忘了写 `.items()` | 写成 `for k, v in d.items()` |
| `SyntaxError` | f-string 里引号冲突 | 外层双引号，内层单引号 |
| `TypeError: unhashable type: 'list'` | 拿列表当键了 | 键只能用字符串/数字/元组 |
