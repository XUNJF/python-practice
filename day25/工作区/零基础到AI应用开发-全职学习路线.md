# 零基础 → AI 应用开发 · 全职学习路线

> 起点：会 Python 基础语法（变量、循环、函数、列表字典），能看懂简单代码，自己写容易卡住。
> 目标：拿到 AI 应用开发方向的初级岗位 offer。
> 前提：全职投入，每天 6-8 小时，每周 5-6 天。
> 周期：约 5 个月（20 周）。

---

## 开始之前，先把三件事说清楚

**一、真正的难点不是 AI，是「能独立写出东西」。**
你现在卡的地方不是不懂 AI 概念，而是离开教程就写不出代码。这只能靠**大量动手**解决，没有捷径，也没有哪门课能替你解决。

**二、写代码的时间必须多于看视频的时间。**
建议比例 **7:3**，最少 **6:4**。如果你一天 6 小时里有 4 小时在看视频，那基本等于没学。看视频是被动的，写代码才是主动的。

**三、每个阶段必须有产出物。**
没有产出物的学习等于没学。下面每个阶段我都写了「验收标准」，达不到就不要往下走——往后堆只会越堆越虚。

**不要买一堆课。** 一门 Python 基础课 + 官方文档 + AI 助手，足够了。囤课是拖延的另一种形式。

---

## 阶段 0（第 0 周）：把环境搭起来

- 装 Python 3.11+、VS Code、Git
- 学会用命令行：进目录、列文件、运行脚本
- 注册一个 AI 助手（就是你正在用的这个），后面遇到问题就靠它

**验收**：能新建一个 .py 文件，在里面写 `print("hello")`，用命令行跑出结果。

---

## 阶段 1（第 1-4 周）：Python 打牢

**学什么**

- 数据结构：列表、字典、集合、元组的常用操作（重点）
- 函数：参数、返回值、默认参数、作用域
- 文件读写：文本、CSV、JSON
- 异常处理：try/except，学会读懂报错信息
- 模块与包：import、pip 安装、虚拟环境
- 面向对象入门：类、属性、方法（够用就行，别死磕）
- 常用库：requests（调接口）、pandas 基础（处理表格）

**产出（必须写完）**

5-8 个小脚本，比如：

1. 批量重命名一个文件夹里的文件
2. 读取 Excel，筛选出符合条件的行，另存一份
3. 调用一个公开 API（天气、汇率都行），把结果打印出来
4. 把 JSON 数据转成 CSV
5. 写个简单的命令行小工具（比如记账、计算器）

**验收**：给你一个没做过的需求（比如「把这个文件夹里所有 .txt 合并成一个，按日期排序」），你能**不查教程**独立写出来。

> 卡住怎么办：先自己查报错，超过 1 小时没进展就直接问 AI 助手，让它给你思路而不是答案，然后自己敲一遍。

---

## 阶段 2（第 5-8 周）：工程基础 + 后端

这一步很多人跳过，但它决定了你能不能做「应用」而不只是「脚本」。

**学什么**

- **Git**：commit、push、分支。所有代码都要传 GitHub——这是你的作品集
- **HTTP 基础**：请求方法、状态码、请求头/响应体，能用 Postman 或 curl 调接口
- **FastAPI**：路由、路径参数、请求体校验（Pydantic）、依赖注入、异步 async/await
- **数据库**：SQLite 起步，学基本 SQL（增删改查、where、join）；了解 PostgreSQL
- **环境变量与配置管理**

**产出**

一个完整的后端服务，比如「待办事项 API」：

- 有增、删、改、查四个接口
- 数据存进数据库，重启不丢
- 代码传到 GitHub，写好 README
- 能本地跑起来，用 curl 或 Postman 测通每个接口

**验收**：能对着自己的项目讲清楚「请求进来以后，代码是怎么一步步处理的」。

---

## 阶段 3（第 9-13 周）：AI 应用核心

现在才开始碰 AI。前面没打牢的话，这一步会变成「照着教程抄，抄完也不懂」。

**学什么**

- **LLM 基础概念**：token、上下文窗口、temperature、幻觉是怎么来的、成本怎么算
- **Prompt Engineering**：结构化提示词、few-shot、思维链
- **调用大模型 API**：选一家（通义、DeepSeek、智谱都行），学会普通调用和**流式输出**
- **RAG（检索增强生成）**：
  - 文本切分（chunk）策略
  - Embedding 与向量
  - 向量数据库（先用轻量的，比如 Chroma）
  - 检索 → 拼上下文 → 生成
- **框架**：先**手写一遍**上面这个流程，再用 LangChain 复现一遍。顺序别反——先懂原理再上框架，不然你会变成只会调 API 的人

**产出**

一个 RAG 问答应用。**建议就用你桌面上那套《深度学习入门》资料当知识库**——用自己的材料做，你会更有动力，也更容易发现问题。

要能跑通：上传/导入文档 → 提问 → 返回带出处的答案。

**验收**：能不看资料，给别人讲清楚 RAG 每一步在干什么、为什么要这么做、效果不好时可能是什么原因。

---

## 阶段 4（第 14-17 周）：Agent + 项目打磨

**学什么**

- **工具调用（function calling）**：让模型能调用你的函数
- **Agent 循环**：模型决定调什么工具 → 执行 → 把结果喂回去 → 再决策
- 多轮对话的状态管理
- 错误处理：工具调用失败怎么办、模型输出格式不对怎么办

**产出**

把阶段 3 的项目升级成一个能拿得出手的作品：

- 加入工具调用（比如查天气、查数据库、算数）
- 支持流式输出、多轮对话
- 前端界面不用太好看，能点就行（Streamlit 或简单 HTML 都可以）
- GitHub 上写清楚的 README：项目做什么、架构图、怎么跑起来

**这块最重要。** 面试时你只有这一个项目能证明自己，它必须能讲 10 分钟不露怯。

**验收**：能画出架构图，能讲清楚每个技术选择「为什么用这个不用那个」。

---

## 阶段 5（第 18-20 周）：求职冲刺

- **简历**：一页，项目放最上面，写清楚做了什么、用到什么、结果是什么
- **八股整理**：RAG 全流程、Prompt 技巧、Agent 设计、模型选型与成本——自己整理一遍，别背别人的
- **项目演练**：把自己讲项目的录音，回放听，找漏洞
- **开始投递**：不要太晚，**第 12 周左右就可以开始投**，边投边学，面试本身就是最好的复习

---

## 明确不要学的东西

现阶段碰都别碰，会严重拖慢你：

- 深度学习理论、transformer 推导、自己训练模型 —— 那是算法岗，不是应用岗
- Go 语言、Kafka、Redis 集群、Kubernetes —— 后端进阶内容，初级应用岗不问
- 各种花哨的新框架 —— 基础没牢之前，学得越多越乱

---

## 每天的时间怎么排

建议模板（每天 6 小时）：

| 时间 | 内容 |
|---|---|
| 1 小时 | 看新知识（视频/文档） |
| 4 小时 | **动手写代码** |
| 1 小时 | 复习 + 写笔记/写 GitHub |

一周留半天做**完整复盘**：这周学了什么、卡在哪、下周做什么。不复盘的话，很容易在原地打转还以为自己在进步。

---

## 最后，两句实在话

**一、这条路比你想的长，但比你想的确定。**
从「会基础语法」到能拿 offer，5-6 个月全职是比较现实的。中间会有「怎么学了半天还是写不出来」的阶段，那很正常，是必经的，不是你不适合。

**二、第 12 周开始就投简历，别等「准备好」。**
你永远不会觉得准备好了。早投能拿到真实反馈，知道市场要什么，比闷头再学两个月有用得多。前期被拒很正常，把它当信息，不是当判决。

**三、简历上没项目，学历平平，那就靠这一个项目打。**
把阶段 3-4 那个 RAG + Agent 项目做扎实，GitHub 上代码干净、README 清楚，比十个半成品强。
