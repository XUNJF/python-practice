# 第 17 天学习笔记 · RAG（一）

> RAG = Retrieval-Augmented Generation，检索增强生成。
> **先找出相关资料，再让 AI 根据资料回答。**

---

## 一、RAG 要解决什么问题

**大模型的训练数据是公开数据。它不知道你的私人资料。**

你问它「我那份产品手册里写了什么」，它要么说不知道，要么**编一个听起来很像的答案**。

**这就是「幻觉」的主要来源之一**：模型不知道自己在瞎编。

---

## 二、笨办法：把资料全塞进 prompt

```
200 页产品手册 + 用户的问题 → 一起发给 AI
```

**不行的三个原因：**

| 问题 | 说明 |
|---|---|
| **太长** | 超出上下文限制，模型一次能看的字数是有限的 |
| **太贵** | 每次提问都要把整本手册重发一遍 |
| **效果反而差** | 无关信息太多，模型抓不住重点 |

**第三条最反直觉**：给的信息多，不等于答得好。**关键信息被淹没在噪音里，模型反而更容易答偏。**

---

## 三、⭐ RAG 的思路

```
用户提问
   ↓
在所有文档里【找出最相关的几段】
   ↓
只把这几段 + 问题 一起发给 AI
   ↓
AI 根据这几段回答
```

**给 AI 的不是「所有资料」，是「跟这个问题相关的那几段」。**

这样：
- 不超长度限制（只发几段）
- 不贵（每次都很少）
- 效果好（全是相关内容）

---

## 四、怎么找「相关」

### 传统搜索：关键词匹配

搜「退款」，只能找到**含「退款」两个字**的段落。

**问题**：用户可能问「我买错了想退钱怎么办」——**一个字都不重合**，就找不到了。

### RAG 用「语义搜索」

**找意思相近的，不看用词。**

**怎么做到？把文字变成一串数字。**

```
"退款"    →  [0.12, -0.83, 0.45, ...]      1024 个数字
"退货"    →  [0.11, -0.79, 0.48, ...]      ← 跟上面很接近
"服务器"  →  [-0.67, 0.22, -0.31, ...]     ← 差很远
```

**含义相近的文字 → 数字串也相近。**

---

## 五、Embedding 是什么

**把一段文字变成一串数字的过程，叫 embedding（嵌入）。**

**那串数字叫「向量」（vector）。**

| 概念 | 意思 |
|---|---|
| **Embedding** | 动作：文字 → 向量 |
| **向量** | 结果：那串数字 |
| **维度** | 数字的个数（bge-m3 是 1024 维） |

### ⚠️ 几个必须知道的点

**① 同一段文字，每次 embedding 出来的结果是一样的。**

它不像大模型那样有随机性——**同样的输入，永远同样的输出。**

**② 向量本身没有意义。**

`[0.12, -0.83, 0.45, ...]` 里每个数字代表什么？**没人能解释。** 它是在一个 1024 维空间里的坐标，人类没法可视化。

**你只需要关心一件事：两段文字的向量离得近不近。**

**③ 不同模型的向量不能混用。**

`bge-m3` 出来的 1024 维向量，和别家模型出来的 1024 维向量，**是两个不同空间里的坐标**——放在一起比较毫无意义。

**换模型 = 所有数据必须重新向量化。**

---

## 六、怎么算「接近」—— 余弦相似度

**算两个向量的夹角。**

| 结果 | 意思 |
|---|---|
| 接近 **1.0** | 意思几乎一样 |
| **0.5 ~ 0.9** | 相关 |
| 接近 **0** | 基本无关 |
| **负数** | 意思相反（少见） |

**不用管公式，记住「越大越像」就行。**

### 参考数值（bge-m3 实测）

| 对比 | 相似度 |
|---|---|
| "想退货怎么办" vs "退款政策：30天内可全额退款" | **0.70** |
| "想退货怎么办" vs "服务器日志保留七天" | **0.50** |

**差 0.2** —— **不算夸张，但排序是对的。** RAG 靠的就是这个排序。

**写错成 `.com` 会连不上。** 这个坑很多人踩过。

## 八、调用的样子

**跟调 DeepSeek 几乎一样**——同样的 headers、同样的 `requests.post`：

```python
import requests

with open("key_sf.txt", encoding="utf-8") as f:
    sf_key = f.read().strip()

response = requests.post(
    "https://api.siliconflow.cn/v1/embeddings",
    headers={
        "Authorization": f"Bearer {sf_key}",
        "Content-Type": "application/json",
    },
    json={
        "model": "BAAI/bge-m3",
        "input": "退款政策：购买后30天内可申请全额退款。",
    },
    timeout=30,
)

data = response.json()
vector = data["data"][0]["embedding"]
print(len(vector))     # 1024
```

### 跟 chat 接口的三个区别

| | chat 接口 | embedding 接口 |
|---|---|---|
| 网址 | `/chat/completions` | **`/embeddings`** |
| 请求体 | `"messages": [...]` | **`"input": "一段文字"`** |
| 返回值 | `choices[0].message.content` | **`data[0].embedding`** |

**返回值是个 1024 个数字的列表。** 打印出来会很长。

## 九、算相似度

**余弦相似度的实现**（只用你已经会的东西）：

```python
import math

def cosine(a, b):
    # 分子：对应位置相乘再相加
    dot = 0
    for i in range(len(a)):
        dot += a[i] * b[i]

    # 分母：两个向量各自的长度
    len_a = 0
    for x in a:
        len_a += x * x

    len_b = 0
    for x in b:
        len_b += x * x

    return dot / (math.sqrt(len_a) * math.sqrt(len_b))
```

**看不懂公式没关系，看代码能理解就行：**

- 分子 `dot` —— 两个向量「有多同向」
- 分母 —— 两个向量各自的长度
- **相除 = 消掉长度的影响，只看方向**

## 十、完整验证代码

```python
import requests
import math

with open("key_sf.txt", encoding="utf-8") as f:
    sf_key = f.read().strip()


def embed(text):
    response = requests.post(
        "https://api.siliconflow.cn/v1/embeddings",
        headers={
            "Authorization": f"Bearer {sf_key}",
            "Content-Type": "application/json",
        },
        json={"model": "BAAI/bge-m3", "input": text},
        timeout=30,
    )
    return response.json()["data"][0]["embedding"]


def cosine(a, b):
    dot = 0
    for i in range(len(a)):
        dot += a[i] * b[i]
    len_a = 0
    for x in a:
        len_a += x * x
    len_b = 0
    for x in b:
        len_b += x * x
    return dot / (math.sqrt(len_a) * math.sqrt(len_b))


# 一段问题，两段文档（一段相关，一段无关）
question = "我买了东西，想退货怎么办？"
related = "退款政策：购买后30天内可申请全额退款。"
unrelated = "服务器日志保留七天，超过期限自动清理。"

v_q = embed(question)
v_rel = embed(related)
v_un = embed(unrelated)

print(f"问题 vs 相关文档：{cosine(v_q, v_rel):.4f}")
print(f"问题 vs 无关文档：{cosine(v_q, v_un):.4f}")
```

**预期结果：第一行明显大于第二行。**

**如果真的是这样——你就亲眼验证了 RAG 的核心机制。**

## 十一、常见报错

| 报错 | 原因 | 解决 |
|---|---|---|
| `401` | key 不对 | 检查 `key_sf.txt`，别忘了 `.strip()` |
| 连不上 | 域名写成 `.com` 了 | 改成 `.siliconflow.cn` |
| `404 model not found` | 模型名写错 | 确认是 `BAAI/bge-m3` |
| `402` | 余额不足 | 确认用的是免费模型 |
| `KeyError: 'data'` | 返回结构不对（通常是报错了） | `print(response.text)` 看真实内容 |
