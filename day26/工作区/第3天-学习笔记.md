## 一、变量：给数据起名字

```python
name = "XUNJF"
age = 25
price = 9.9
```

等号左边是名字，右边是内容。

**关键理解**：等号不是数学里的「相等」，是「**把右边装进左边**」。所以下面这样也是合法的：

```python
x = 1
x = x + 1    # x 现在是 2，先算右边，再装回左边
```

## 二、input：接收用户输入

```python
name = input("请输入你的名字：")
print("你好，" + name)
```

`input` 会暂停程序，等你打字、按回车。你输入的内容就存进变量了。

### ⚠️ 最容易踩的坑：input 拿到的永远是文字

```python
age = input("年龄：")     # 你输入 25，age 其实是字符串 "25"
```

要当数字用，必须转换：

```python
age = int(input("年龄："))       # 转整数
height = float(input("身高："))  # 转小数
```

**报错 `TypeError` 或结果莫名其妙，第一件事就是检查有没有转类型。**

## 三、if：做判断

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

`elif` = else if，可以写很多个。`else` 收尾，可省略。

### ⚠️ 两个格式要求（新手最常错）

1. 条件后面必须有 **冒号 `:`**
2. 下面那行必须 **缩进**（按 Tab 或 4 个空格）

Python 靠缩进判断「哪些代码属于这个 if」，缩进错了程序逻辑就错了。

### 比较运算符

| 符号 | 意思 |
|---|---|
| `==` | 等于（**两个等号**，一个等号是赋值） |
| `!=` | 不等于 |
| `>` `<` `>=` `<=` | 大于 / 小于 / 大于等于 / 小于等于 |

## 四、循环：重复干活

### for 循环——跑固定次数

```python
for i in range(5):
    print(i)          # 打印 0 1 2 3 4
```

⚠️ **range(5) 是 0 到 4，不包括 5**。这个「左闭右开」规则后面天天用。

指定范围：

```python
for i in range(1, 6):     # 1 2 3 4 5
for i in range(1, 10, 2): # 1 3 5 7 9，第三个参数是「每次加几」
```

### while 循环——条件满足就一直跑

```python
count = 0
while count < 3:
    print(count)
    count = count + 1
```

⚠️ **while 一定要有能让条件变假的语句**（上面那句 `count = count + 1`），否则会无限循环，程序卡死，得用 `Ctrl+C` 强制停止。

### 两者怎么选

- 知道要跑几次 → 用 `for`
- 不知道要跑几次，跑到满足条件为止 → 用 `while`（比如「让用户一直猜，直到猜对」）

## 五、今天常见报错速查

| 报错 | 原因 | 怎么修 |
|---|---|---|
| `SyntaxError: expected ':'` | if / for / while 后面漏了冒号 | 补上 `:` |
| `IndentationError` | 缩进不对（少了或多空格混用） | 统一用 Tab 或统一用 4 空格 |
| `TypeError: can only concatenate str` | 字符串和数字直接相加了 | 用 `str()` 转一下，或用 f-string |
| `ValueError: invalid literal for int()` | `int()` 里放了非数字的文字 | 检查用户输入了什么 |
| 程序卡住不动 | while 死循环 | 按 `Ctrl+C` 停掉，检查循环条件 |

## 六、f-string：更好用的输出方式（进阶但立刻有用）

```python
name = "XUNJF"
age = 25
print(f"我叫{name}，今年{age}岁")
```

字符串前面加 `f`，里面用 `{}` 直接放变量，比 `"我叫" + name` 这种拼接清爽得多。**推荐从现在开始就用它。**

## 七、Git 提交三连（每天必练）

```
pwd                          # 先确认自己在项目目录里！
git status                   # 看看改了哪些文件
git add .                    # 全部加入待提交
git commit -m "说明这次改了什么"
git push                     # 上传（第一次用了 -u，之后不用再写）
```

**`pwd` 这一步不能省。** 敲 git 命令前先确认位置，是终身受用的习惯。
