# 第 6 天学习笔记 · 函数（function）

> 函数 = 把一段代码打包起来，起个名字，以后想用就喊一声。

---

## 一、为什么需要函数

### 看你自己的代码

**购物清单**的菜单：
```python
print("1. 查看清单")
print("2. 添加商品")
print("3. 删除商品")
print("4. 退出")
```

**通讯录**的菜单：
```python
print("1. 查看全部")
print("2. 添加联系人")
print("3. 查找联系人")
print("4. 删除联系人")
print("5. 退出")
```

**几乎一模一样。** 而且它们都写在 `while` 循环里——每循环一次就要执行一遍这段代码。

问题在哪？

**① 想改就得改多处。** 比如想把「1.」改成「【1】」，所有写了菜单的地方都得改。

**② 主程序被淹没在细节里。** 看你的通讯录主循环，六七行菜单打印占了大半，真正的逻辑（if/elif）反而不显眼。

**函数解决的就是这个：写一次，到处调用。**

---

## 二、最简单的函数

```python
def greet():
    print("你好")

greet()        # 调用它 → 输出：你好
greet()        # 再调一次 → 输出：你好
```

两个部分：

**`def greet():`** —— 定义。「我要造一个叫 greet 的东西」，注意**冒号**。

**`greet()`** —— 调用。「现在执行它」。

⚠️ **定义和调用是两回事。** 只写 `def greet():` 不写 `greet()`，什么都不会发生——你只是造了台机器，没按开关。

---

## 三、参数：让函数能接收数据

上面那个 `greet()` 每次都输出「你好」，太死板。想让它能问候不同的人：

```python
def greet(name):
    print(f"你好，{name}")

greet("张三")      # 你好，张三
greet("李四")      # 你好，李四
```

**`name` 叫「参数」**，是函数内部用的变量名。

**`"张三"` 叫「实参」**，是你实际传进去的值。

**不用记这两个术语**，只要理解：**括号里的东西，是函数干活需要的数据。**

### 多个参数

```python
def add(a, b):
    print(a + b)

add(3, 5)          # 8
```

逗号隔开，按顺序对应。

### 默认参数

```python
def greet(name, greeting="你好"):
    print(f"{greeting}，{name}")

greet("张三")                 # 你好，张三（用了默认值）
greet("张三", "早上好")        # 早上好，张三（覆盖了默认值）
```

**有默认值的参数必须放在后面。** 写成 `def greet(greeting="你好", name)` 会报语法错误。

## 四、⭐ 最重要的一节：`return` 和 `print` 的区别

**这是学函数时最容易搞混的地方。**

### 先看区别

```python
def add_print(a, b):
    print(a + b)          # 只是「显示出来」

def add_return(a, b):
    return a + b          # 把结果「交出去」
```

**用它们试试：**

```python
x = add_print(3, 5)     # 屏幕上显示 8
print(x)                # 显示 None  ← 拿不到结果

y = add_return(3, 5)    # 屏幕上什么都不显示
print(y)                # 显示 8     ← 结果拿到手了
```

### 为什么会这样

**`print` 只是把东西显示在屏幕上，然后就没了。** 它不是结果，只是「打印出来给人看的」。

**`return` 是把结果「还给」调用者**，调用者可以接住它：

```python
result = add_return(3, 5)     # result 就是 8
result = result * 2           # 可以继续用 → 16
```

### 一句话记住

| | 作用 | 之后还能用吗 |
|---|---|---|
| `print` | 显示给人看 | ❌ 不能 |
| `return` | 把结果交给程序 | ✅ 能 |

**`print` 是给用户看的，`return` 是给程序用的。**

### 什么时候用哪个

**只 return，不 print** —— 推荐。函数负责算，显示交给外面：

```python
def add(a, b):
    return a + b

print(add(3, 5))        # 需要显示的时候再显示
```

**好处**：这个函数既可以在命令行用，也能在网页后端用，还能在别的函数里用。**如果函数内部写死了 print，就只能在屏幕上看了。**

**两个都不写** —— 打印菜单这种「只为了显示」的函数：

```python
def show_menu():
    print("1. 查看清单")
    print("2. 添加商品")
    ...
```

这种函数本来就只是显示，不需要返回值。

## 五、`None` 是什么

**没有 `return` 的函数，返回值是 `None`。**

```python
def greet(name):
    print(f"你好，{name}")

x = greet("张三")       # 显示：你好，张三
print(x)                # 显示：None
```

`None` 是 Python 里表示「什么都没有」的特殊值。

**判断方法**：

```python
if x is None:
    print("没拿到东西")
```

## 六、返回多个值

Python 允许一次返回多个：

```python
def get_stats(numbers):
    return sum(numbers), max(numbers), min(numbers)

total, big, small = get_stats([85, 92, 78])
print(total)     # 255
print(big)       # 92
print(small)     # 78
```

**本质上返回的是一个「元组」**，左边用逗号接住就自动拆开了。以后会经常用到。

## 七、作用域（先有个印象）

**函数内部定义的变量，外面看不见：**

```python
def test():
    x = 10          # 只在函数内部存在

test()
print(x)            # ❌ NameError: name 'x' is not defined
```

**为什么这么设计**：每个函数有自己的「小房间」，互不干扰。否则你在大项目里给变量起名字会寸步难行——总不能让全世界只能用这几百个名字。

**⚠️ 常见坑**：函数里想改外面的变量，得用 `global` 声明（但**不推荐**，尽量避免）。正确做法是用参数传进去、用 return 传出来。

---

## 八、函数该多长？

**一个经验法则：一个函数只做一件事。**

**太长（不好）**：
```python
def do_everything():
    # 显示菜单
    # 接收输入
    # 判断选项
    # 增删改查
    # 保存文件
    ...（100行）
```

**拆开（好）**：
```python
def show_menu():
    ...

def add_contact(contacts):
    ...

def find_contact(contacts, name):
    ...
```

**判断标准**：如果你需要用「然后」来描述这个函数做了什么（「先显示菜单，**然后**获取输入，**然后**……），说明它该拆了。

**好处**：好读、好改、好测。出问题时能精确定位到是哪个函数。

```python
def main():
    # 主循环
```

**目标**：改造完，主循环应该变成这样清爽的样子——

```python

    show_menu()
```

## 练习 2：小函数练手

写这几个，练熟「参数怎么传、结果怎么拿」：

1. `max_of_two(a, b)` —— 传两个数，**返回**较大的那个
2. `average(numbers)` —— 传一个列表，**返回**平均值
3. `is_even(n)` —— 判断是不是偶数，**返回** `True` / `False`

**⚠️ 都要求用 `return`，不要用 `print`。**

写完之后这样验证：

```python
print(max_of_two(3, 7))        # 应该输出 7
print(average([85, 92, 78]))   # 应该输出 85.0
print(is_even(4))              # 应该输出 True
print(is_even(7))              # 应该输出 False
```

**能用 `print` 包住你的函数调用并拿到结果，就说明 return 写对了。**

# 常见报错

| 报错 | 原因 | 怎么修 |
|---|---|---|
| `NameError: name 'xxx' is not defined` | 函数没定义，或变量作用域不对 | 检查函数名拼写、定义顺序 |
| `TypeError: xxx() missing 1 required positional argument` | 调用时参数没给够 | 检查括号里传了几个 |
| `TypeError: xxx() takes 0 positional arguments but 1 was given` | 调用时多传了参数 | 定义里没写参数却传了值 |
| 拿到 `None` | 函数没写 `return` | 检查是不是只写了 `print` |
| `SyntaxError: non-default argument follows default argument` | 默认参数放在前面了 | 有默认值的参数放最后 |
