# 第 7 天学习笔记 · 文件读写

> 让数据活过程序结束——这是文件存在的意义。

---

## 一、为什么需要文件

变量里的数据，**程序一结束就没了**。

你的通讯录每次打开都是那两个写死的人，就是因为联系人只活在内存里。**文件让数据能存下来，下次打开还在。**

---

## 二、⚠️ 三种模式（最重要的一节）

| 模式 | 含义 | 危险吗 |
|---|---|---|
| `"r"` | 读。文件必须已存在 | 安全 |
| `"w"` | 写。**会把原内容全部清空** | ⚠️ 危险 |
| `"a"` | 追加。在末尾接着写 | 安全 |

### 演示：`"w"` 的后果

```python
# 第一次：写入两行
with open("note.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")
```
文件内容：
```
第一行
第二行
```

```python
# 第二次：用 "w" 再写一行
with open("note.txt", "w", encoding="utf-8") as f:
    f.write("新的一行\n")
```
文件内容：
```
新的一行          ← 前两行没了！
```

**换成 `"a"`：**
```python
with open("note.txt", "a", encoding="utf-8") as f:
    f.write("新的一行\n")
```
文件内容：
```
第一行
第二行
新的一行          ← 保留了
```

**结论**：`"w"` 是「推倒重来」，`"a"` 是「后面接上」。

## 三、基本写法：`with`

```python
# 写
with open("note.txt", "w", encoding="utf-8") as f:
    f.write("内容\n")

# 读（一次性全读出来）
with open("note.txt", "r", encoding="utf-8") as f:
    content = f.read()
print(content)
```

### 逐行拆解

```python
with open("note.txt", "w", encoding="utf-8") as f:
```

| 部分 | 含义 |
|---|---|
| `open(...)` | 打开文件 |
| `"note.txt"` | 文件名（默认在当前目录） |
| `"w"` | 模式 |
| `encoding="utf-8"` | 编码，**中文必写** |
| `as f` | 把文件对象命名为 `f` |
| `with` | **自动关闭文件** |

### 为什么必须用 `with`

手动开关文件很容易忘记 `.close()`，一旦忘记，**数据可能根本没写进磁盘**。

`with` 保证不管中途出什么错（哪怕程序崩了），文件都会被正确关闭。

**从现在开始，一律用 `with`，不要手写 `open` + `close`。**

---

## 四、⚠️ 中文必踩坑：`encoding="utf-8"`

**这个参数对你不是可选项。**

Windows 中文版的 Python **默认用 GBK 编码**打开文件。后果：

- 你写的「你好」以 GBK 存进文件
- 别人（或用 UTF-8 的工具）打开 → **乱码**
- 反过来也一样

**规则：只要文件里可能出现中文，`encoding="utf-8"` 一个字都别省。**

---

## 五、逐行读文件

```python
with open("note.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line)
```

### ⚠️ 会有多余空行

每行末尾本来就有一个 `\n`，`print` 又会自动加一个换行 → 结果空两行。

**解决：`.strip()`**

```python
    for line in f:
        print(line.strip())
```

`strip()` 去掉字符串**首尾**的空白和换行符。

### 读成列表

```python
with open("note.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()          # 每一行是一个元素，末尾带 \n

# 想去掉 \n 可以这样
lines = [line.strip() for line in lines]
```

## 六、JSON：存字典和列表

`f.write()` 只能写**字符串**。想存字典或列表，用 JSON。

```python
import json

contacts = {"张三": "138", "李四": "139"}

# 存进文件
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(contacts, f, ensure_ascii=False, indent=2)

# 从文件读出来
with open("data.json", "r", encoding="utf-8") as f:
    contacts = json.load(f)
```

### 两个参数必须写

| 参数 | 作用 | 不写的后果 |
|---|---|---|
| `ensure_ascii=False` | 保留中文 | 中文变成 `张三`，文件没法看 |
| `indent=2` | 缩进美化 | 全部挤在一行 |

### 为什么用 JSON

- 所有编程语言都认识它
- **网络接口传数据的标准格式**
- 人能读懂

**你后面做 AI 应用时，调用大模型 API 传出去和收回来的，全是 JSON。** 今天学的不只是为了存通讯录。

---

## 七、四个容易混的函数

| 函数 | 从哪到哪 | 记忆方法 |
|---|---|---|
| `json.dump` | 字典 → **文件** | 不带 s，对**文件** |
| `json.dumps` | 字典 → **字符串** | 带 s，就是 **string** |
| `json.load` | **文件** → 字典 | 不带 s，对**文件** |
| `json.loads` | **字符串** → 字典 | 带 s，就是 **string** |

## 八、判断文件是否存在

```python
import os

if os.path.exists("contacts.json"):
    # 文件存在，读进来
    with open("contacts.json", "r", encoding="utf-8") as f:
        contacts = json.load(f)
else:
    # 第一次运行，用默认值
    contacts = {"张三": "1381525"}
```

另一种写法（更 Python 风格，但异常处理还没学）：

```python
try:
    with open("contacts.json", "r", encoding="utf-8") as f:
        contacts = json.load(f)
except FileNotFoundError:
    contacts = {"张三": "1381525"}
```

**两种都行，先用 `os.path.exists` 那种。**

## 九、常用速查

```python
# 写文本（覆盖）
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("内容\n")                # 注意自己加 \n

# 写文本（追加）
with open("a.txt", "a", encoding="utf-8") as f:
    f.write("新内容\n")

# 读全部文本
with open("a.txt", "r", encoding="utf-8") as f:
    text = f.read()

# 逐行读
with open("a.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

# 存字典
with open("d.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# 读字典
with open("d.json", "r", encoding="utf-8") as f:
    data = json.load(f)
```

# 常见报错

| 报错 | 原因 | 怎么修 |
|---|---|---|
| `FileNotFoundError` | 用 `"r"` 打开一个不存在的文件 | 先 `os.path.exists` 判断，或用 `"a"` |
| `UnicodeDecodeError` | 编码不对 | 加上 `encoding="utf-8"` |
| `JSONDecodeError` | 文件不是合法的 JSON（可能被清空了） | 检查文件内容 |
| 写进文件的中文是乱码 | 没写 `encoding="utf-8"` | 加上 |
| JSON 里中文变成 `张` | 没写 `ensure_ascii=False` | 加上 |
| 打印出现空行 | 没 `.strip()` | 加上 |
