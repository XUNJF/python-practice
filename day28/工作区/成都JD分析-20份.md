# 成都 20 份 JD 分析

> 数据来源：你自己收集的 20 份成都岗位（6 份文字 + 14 份截图）。
> 用途：校准学习方向，判断哪些能力值得投入、哪些可以跳过。

---

## 一、最反直觉的一条：门槛比你以为的低

**「经验不限」是主流，不是例外。** 20 份里绝大多数在经验那一栏写的是「经验不限」。

更关键的是——**明确写「接受应届毕业生」的有好几份**（JD 8、JD 9、JD 14 等），而且**只有 1 份明确卡了毕业年份**（要求「2026 年及以后毕业」）。

也就是说，我前面担心的「你 2026 届、校招不要你、社招要经验」这个问题，**在成都市场没有我以为的那么严重**。大量岗位是校招社招混着挂的，不卡身份。这是好消息，你可以把主要精力放在技术上，而不是焦虑身份。

**学历**：几乎全部写「本科及以上」，你符合。只有 1 份（JD 4）写「大专及以上」，而且明说「应届生、零基础系统学习 Python、转行求职者可接纳培养」——那是门槛最低的一份，可以当保底。

---

## 二、高频技术栈排行

按 20 份里出现的频次排序，这个排序基本就是你的**学习优先级**：

| 技术 | 出现频次 | 说明 |
|---|---|---|
| **Python** | 几乎 100% | 没得商量，必须扎实 |
| **大模型 API 调用 / Prompt 工程** | 很高 | AI 岗的入场券 |
| **RAG（检索增强生成）** | 很高 | 成都 AI 岗的核心关键词 |
| **Agent / LangChain / LangGraph** | 很高 | 和 RAG 并列为两大核心 |
| **Git / Linux / Docker** | 很高 | **Docker 几乎每个 AI 岗都提** |
| **RESTful API / 后端开发** | 很高 | 说明「会写接口」是硬要求 |
| **MySQL / PostgreSQL** | 很高 | 数据库跑不掉 |
| **数据结构与算法** | 中高 | 面试会考基础 |
| **向量数据库**（Milvus/Chroma/Qdrant） | 中高 | RAG 的配套 |
| **FastAPI / Flask** | 中 | **AI 岗几乎都写 FastAPI** |
| **Django / DRF** | 中 | 主要出现在传统后端岗 |

**一个重要观察**：**FastAPI 出现在 AI 岗，Django 出现在传统后端岗。** 你原计划学 FastAPI 是对的方向，不用改。但如果要兼顾投传统后端岗，Django 也得会一点。

## 三、薪资分布（成都，本科，经验不限）

| 区间 | 大致份数 | 对应岗位 |
|---|---|---|
| 7-12K | 约 6 份 | Python 开发、初级 AI 工程师、AI Agent |
| 10-15K | 约 5 份 | AI 应用工程师、Agent 开发 |
| 12-25K | 约 4 份 | AI 应用开发（要求更高，要项目经验） |
| 面议 | 1 份 | 2027 届校招 |

**对你的意义**：**7-12K 那一档才是你的现实靶心**，不是 15-25K 那些。那些高薪岗位都要求「有 AI 项目实战经验」，你第一份工作够不到。但这不影响——先进 7-12K 的岗位干一年，第二份工作就能往上跳。

---

## 四、最值得注意的一份：JD 16

有一份岗位（7-12K·13 薪）的要求是这样的：

> **核心要求（必须项）**
> 1. 使用 claude code、codex 等 AI 开发工具指挥 AI 进行代码撰写
> 2. 具备完整的系统开发思路
> 3. 擅长开发语言不限
>
> **任职要求**
> 1. 需提供通过 AI 开发的项目实例（GitHub 链接）
> 2. 简要说明，自己通过 AI 的开发流程

**这份岗位几乎是为你的现状写的。**

它不要你会几门语言，不要你算法多强，不要你几年经验——它要的是「**你能用 AI 工具把东西做出来，并且能讲清楚你怎么做的**」。

你现在就在用 Claude。这条路你已经在上面了。

**这意味着你的学习策略可以有个重要调整**：不必等到「Python 精通 + 背完八股」才去投简历。**边学边用 AI 工具做出真实项目、传到 GitHub**，这个方向你比其他零基础的人有明显优势。

## 五、对你学习计划的调整建议

对照你那份路线，需要补和需要加重的：

**必须新增（原计划里没有）**

- **Docker** —— 几乎每个 AI 岗都提，而且门槛不高，一两周能上手。**优先级很高**
- **Linux 常用命令** —— 同上，投简历前必须会
- **向量数据库** —— 至少会用一种，Chroma 最容易上手

**需要加重（原计划里有但份量不够）**

- **RAG** —— 权重提高。这是成都 AI 岗出现频率最高的关键词，你原来只给了一个阶段，实际应该贯穿始终
- **Prompt 工程** —— 同上
- **后端接口开发** —— 20 份里几乎都要求「会写 RESTful API」，不只是会写脚本

**可以保持**

- Python 打基础（阶段 1）—— 不变，这是根
- FastAPI（阶段 2）—— 方向对，AI 岗几乎都写它

**可以继续跳过**

- 深度学习理论、模型训练、Transformer 推导 —— 20 份里只有 3 份提到，大部分岗位不需要
- Go 语言 —— 只有零星出现
- Kafka、Redis 集群、K8s —— 一份都没直接要求

## 六、战略结论

**主攻方向**：Python + RAG + Agent 的 AI 应用开发。这是成都市场的主流需求，也是你原计划的方向，不用改。

**突破口**：JD 16 那一类「AI 工具驱动开发」的岗位。要求最贴近你现状，而且你已经在用 Claude——这是你相对其他零基础求职者的真实优势。

**保底**：JD 4 那一类「零基础可培养」的岗位。薪资低一些，但能进门。

**靶心薪资**：7-12K。别盯着 15-25K 那些焦虑，等你有了第一份工作，那些自然会向你打开。

**最重要的行动**：**尽快开始往 GitHub 传东西。** 这 20 份 JD 里反复出现「有项目经验者优先」「提供 GitHub 链接」——在成都这个市场，**一个能打开看的项目，比任何证书都有说服力**。你不用等项目做完才传，从第一个小脚本开始就传，让人看到你的成长轨迹。
