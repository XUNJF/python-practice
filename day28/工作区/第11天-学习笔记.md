# 第 11 天学习笔记 · 面向对象（class）

> 把「散在各处的变量和函数」打包成一个整体。

## 一、为什么需要类

看你之前的代码：

```python
SYSTEM = "你是一个Python助教..."
messages = []
headers = {...}

while True:
    ...              # 对话逻辑
```

**想再加一个助手**（比如写作助手）就麻烦了：

```python
SYSTEM_WRITER = "..."
messages_writer = []
headers_writer = {...}
while True:
    ...              # 逻辑要重写一遍
```

**每个助手都要复制一整套。** 三个助手就是三份，改一处要改三遍。

**类干的事：把「一个助手需要的所有东西」打包起来。**

---

## 二、class 是模具，实例是造出来的东西

```python
class ChatBot:          # 模具（类）
    pass                # pass 表示「先空着」

bot1 = ChatBot()        # 造一个（实例/对象）
bot2 = ChatBot()        # 再造一个
```

**`类名()` 就是「造一个」的意思。**

**关键**：`bot1` 和 `bot2` 是**两个独立的个体**——就像同一个模具压出来的两个零件，长得一样，但是两个东西。

---

## 三、`__init__` —— 出厂设置

```python
class ChatBot:
    def __init__(self, name):
        self.name = name
        self.messages = []
```

**它不用你调用，一造出来就自动执行。**

```python
bot = ChatBot("助教")      # 这一行会触发 __init__
```

`__init__` 执行完，这个对象身上就多了两个东西：`name` 和 `messages`。

**名字前后各两个下划线**（`__init__`）是 Python 的固定写法，表示「这是给 Python 自己用的特殊方法」。

## 四、⭐ `self` 是什么（最大的困惑点）

**`self` = 「这个对象自己」。**

### 看翻译就懂了

你写：

```python
bot1.add("你好")
```

Python 实际执行的是：

```python
ChatBot.add(bot1, "你好")
        ↑          ↑
      类名     对象自己，作为第一个参数传进去
```

**所以方法里的 `self`，就是外面的 `bot1`。**

**这就是为什么 `self.messages` 拿到的是「bot1 的 messages」。**

### 所以

- 方法定义的第一个参数**必须写 `self`**（那是留给「对象自己」的位置）
- 在方法里，`self.xxx` = 「这个对象自己的 xxx」
- 名字其实可以随便起，但**全世界都写 `self`，照写就行**

## 五、属性 vs 方法

```python
class ChatBot:
    def __init__(self, name):
        self.name = name          # 属性：存数据
        self.messages = []        # 属性

    def add(self, text):          # 方法：会做的事
        self.messages.append(text)
```

| | 写法 | 使用 | 是什么 |
|---|---|---|---|
| **属性** | `self.name = ...` | `bot1.name` | 它**有什么** |
| **方法** | `def add(self): ...` | `bot1.add("x")` | 它**能做什么** |

⚠️ **属性不带括号，方法带括号。**

`bot1.name` ✓  /  `bot1.name()` ✗

## 六、完整例子

```python
class ChatBot:
    def __init__(self, name):
        self.name = name
        self.messages = []

    def add(self, text):
        self.messages.append(text)
        print(f"{self.name} 现在有 {len(self.messages)} 条消息")

    def clear(self):
        self.messages = []
        print(f"{self.name} 的记录已清空")


bot1 = ChatBot("助教")
bot2 = ChatBot("写作助手")

bot1.add("什么是变量")      # 助教 现在有 1 条消息
bot1.add("什么是列表")      # 助教 现在有 2 条消息
bot2.add("帮我写标题")      # 写作助手 现在有 1 条消息

print(bot1.messages)   # ['什么是变量', '什么是列表']
print(bot2.messages)   # ['帮我写标题']       ← 互不干扰
```

## 七、把 AI 助手改成类

### 目标结构

```python
class ChatBot:
    def __init__(self, system_prompt):
        self.system = system_prompt
        self.messages = [{"role": "system", "content": system_prompt}]

    def chat(self, question):
        # 1. 把问题加进 self.messages
        # 2. 发请求
        # 3. 把回答加进 self.messages
        # 4. return 回答

    def save(self, filename):
        # 存文件

    def load(self, filename):
        # 读文件
```

### 用起来

```python
bot = ChatBot("你是一个Python助教")
print(bot.chat("什么是变量？"))
bot.save("history.json")
```

**对比一下**：原来所有东西散在顶层，现在**一行就造出一个完整助手**。

## 八、⚠️ 类里的方法要用 `self.` 访问自己的东西

**这是新手最容易错的地方：**

```python
class ChatBot:
    def __init__(self, system_prompt):
        self.messages = [{"role": "system", "content": system_prompt}]

    def chat(self, question):
        messages.append({"role": "user", "content": question})   # ✗ 报错！
```

**报 `NameError: name 'messages' is not defined`** —— 因为在方法里，`messages` 这个名字不存在。

**必须写 `self.messages`：**

```python
        self.messages.append({"role": "user", "content": question})   # ✓
```

**规则：凡是这个对象自己存的东西，都要用 `self.` 开头。**

## 九、为什么要用类（总结）

| 好处 | 说明 |
|---|---|
| **打包** | 相关的数据和方法放在一起，不再散落 |
| **隔离** | 多个对象各管各的，互不影响 |
| **复用** | 一个类，造无数个对象 |
| **好读** | `bot.chat("...")` 比一堆散函数清楚 |

---

## 十、什么时候该用类

**判断标准**：当你发现「**有几样数据，总是成组地出现，而且有几件事总是围着这几样数据转**」——那就该打包成类了。

你现在的助手完全符合：

- 数据：`system`、`messages`
- 围绕它们的事：`chat`、`save`、`load`

**所以它该是一个类。**
