# 第一部分：列表（list）

## 一、什么是列表

一排有序的格子，用方括号包起来：

```python
fruits = ["苹果", "香蕉", "橙子"]
numbers = [3, 1, 4, 1, 5]
mixed = ["张三", 25, 3.14, True]     # 什么类型都能放
empty = []                            # 空列表，后面往里装东西用
```

## 二、索引：从 0 开始

```python
fruits = ["苹果", "香蕉", "橙子"]

fruits[0]    # 苹果    ← 第一个是 0，不是 1
fruits[1]    # 香蕉
fruits[2]    # 橙子
fruits[-1]   # 橙子    ← 负数表示从后往前数
fruits[-2]   # 香蕉
```

⚠️ **最常犯的错：`IndexError: list index out of range`**
意思是你访问了不存在的格子。3 个元素的列表，索引只能是 0、1、2，写 `[3]` 就报错。

## 三、常用操作速查

```python
fruits = ["苹果", "香蕉"]

# 增加
fruits.append("橙子")        # 加到末尾 → ["苹果", "香蕉", "橙子"]
fruits.insert(0, "梨")       # 插到指定位置 → ["梨", ...]

# 删除
fruits.remove("香蕉")        # 按「值」删
del fruits[0]                # 按「索引」删
last = fruits.pop()          # 删掉最后一个，并把它返回给你

# 修改
fruits[0] = "葡萄"           # 直接赋值就改了

# 查询
len(fruits)                  # 长度（几个元素）
"苹果" in fruits             # True / False，判断在不在
fruits.index("橙子")         # 找出它的位置

# 排序
numbers = [3, 1, 4, 1, 5]
numbers.sort()               # 从小到大，直接改原列表
numbers.sort(reverse=True)   # 从大到小
```

## 四、遍历

### 只要元素

```python
for fruit in fruits:
    print(fruit)
```

**注意这个写法和之前不一样**——不用 `range` 了，直接 `for 变量 in 列表`。

### 同时要索引

```python
for i in range(len(fruits)):
    print(i, fruits[i])
```

### 更优雅的写法：enumerate

```python
for i, fruit in enumerate(fruits):
    print(i, fruit)
```

效果和上面一样，但更简洁。**推荐用这个。**

## 五、常用的内置函数

```python
numbers = [3, 1, 4, 1, 5]

sum(numbers)      # 15   求和
max(numbers)      # 5    最大值
min(numbers)      # 1    最小值
len(numbers)      # 5    个数
sorted(numbers)   # 返回排好序的新列表，不改原列表
```

## 六、列表切片（进阶，但很有用）

```python
nums = [0, 1, 2, 3, 4, 5]

nums[1:4]      # [1, 2, 3]      从索引1到3（不包括4）
nums[:3]       # [0, 1, 2]      从头到索引2
nums[3:]       # [3, 4, 5]      从索引3到最后
nums[:]        # 全部（复制一份）
```

**规则：`[开始:结束]`，包含开始，不包含结束。** 和 `range` 一个逻辑。

# 第二部分：字典（dict）

## 一、什么是字典

列表是「按位置」找东西，字典是「**按名字**」找东西。

```python
person = {
    "name": "张三",
    "age": 25,
    "city": "成都"
}
```

花括号 `{}`，每项是 `键: 值` 的形式。**键一般是字符串，值可以是任何东西。**

## 二、取值

```python
person["name"]        # 张三
person["age"]         # 25
person["gender"]      # ❌ KeyError：这个键不存在
```

**安全的取值方式**（键不存在也不报错）：

```python
person.get("gender")            # None（表示「没有」）
person.get("gender", "未知")    # 未知（给个默认值）
```

**推荐用 `get()`**，尤其是处理不确定的数据时。

## 三、常用操作

```python
person = {"name": "张三", "age": 25}

# 增加 / 修改（写法一样：有就改，没有就加）
person["city"] = "成都"
person["age"] = 26

# 删除
del person["city"]
person.pop("age")

# 查询
"name" in person           # True，判断键在不在
len(person)                # 有几个键值对
person.keys()              # 所有键
person.values()            # 所有值
person.items()             # 所有键值对
```

## 四、遍历字典

```python
person = {"name": "张三", "age": 25, "city": "成都"}

# 只要键
for key in person:
    print(key)

# 要键和值（最常用）
for key, value in person.items():
    print(f"{key}: {value}")
```

## 五、列表套字典（重点！）

**这是真实数据最常见的形态**，比如从接口拿回来的数据就是这样：

```python
students = [
    {"name": "张三", "score": 85},
    {"name": "李四", "score": 92},
    {"name": "王五", "score": 78},
]

for stu in students:
    print(f"{stu['name']} 考了 {stu['score']} 分")

# 找出最高分的人
best = students[0]
for stu in students:
    if stu["score"] > best["score"]:
        best = stu
print(f"最高分是 {best['name']}")
```

⚠️ 注意 `stu['name']` 里面用**单引号**——因为外层 f-string 已经用了双引号，里面再用双引号会冲突。

# 常见报错速查

| 报错 | 意思 | 怎么修 |
|---|---|---|
| `IndexError: list index out of range` | 索引超出范围 | 检查索引是不是 >= 列表长度 |
| `KeyError` | 字典里没有这个键 | 用 `.get()`，或先判断 `in` |
| `AttributeError: 'list' object has no attribute` | 方法名写错了 | 检查拼写，比如 `append` 不是 `appendd` |
| `TypeError: 'int' object is not iterable` | 对数字用了 for | 检查 for 后面跟的是不是列表 |
