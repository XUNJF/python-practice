## 二、为什么现在学它——你自己已经踩到这个坑了

看你写过的两个程序：

**购物清单**里的菜单：
```python
print("1. 查看清单")

print("3. 删除商品")

```

**通讯录**里的菜单：
```python
print("1. 查看全部")

```

**两段代码长得几乎一样。** 而且你发现没有——**每个 while 循环里都要把它写一遍**，以后想加个选项，两个地方都得改。

这就是函数要解决的问题：**同一段逻辑写一次，到处调用。**

## 三、明天会讲到的东西

### 核心三件套

**① `def` —— 定义函数**

```python
def 函数名():
    函数体
```

**② 参数 —— 把数据传进去**

让函数能接收不同的输入，而不是写死。比如：

```python
def greet(name):
    print(f"你好，{name}")
```

**③ `return` —— 把结果传出来**

这是明天**最重要、也最容易搞混**的一点。

---

### ⚠️ 明天最大的坑：`print` 和 `return` 的区别

很多人卡在这里，明天会重点讲清楚：

| | `print` | `return` |
|---|---|---|
| 作用 | 把东西**显示在屏幕上** | 把结果**交给调用者** |
| 之后能不能用 | 不能，只是给人看的 | 能，可以被继续使用 |

简单说：**`print` 是给用户看的，`return` 是给程序用的。**

一个函数可以只 print 不 return，也可以只 return 不 print，也可以两个都有。什么时候用哪个，明天讲。

---

### 其他会提到的

- **默认参数**：`def greet(name, greeting="你好")` —— 不传就用默认值
- **变量作用域**：函数内部定义的变量，外面看不见（这个先有印象就行）

## 四、明天要做的练习

### 练习 1：把你写过的代码改造成函数

不是写新代码，而是**把昨天的通讯录改造一遍**：

- 菜单打印 → 抽成一个函数
- 查看全部 → 抽成一个函数
- 添加联系人 → 抽成一个函数
- ……

改完你会发现：**主循环变得非常短、非常好读**，一眼就能看出程序在干什么。

**这个练习的价值在于「重构」**——不改功能，只改结构。这是真实开发里天天做的事。

### 练习 2：写几个小函数

练熟「有参数、有返回值」的写法。比如：

- 写一个函数，传两个数，返回较大的那个
- 写一个函数，传一个列表，返回平均值
- 写一个函数，判断一个数是不是偶数，返回 `True`/`False`

这些都很短，但能让你把「参数怎么传、结果怎么拿」练成肌肉记忆。
