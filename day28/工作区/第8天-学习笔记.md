# 第一部分：模块（module）

## 一、一个 `.py` 文件就是一个模块

你已经在用了：

```python
import json
import os
import math
```

**用的时候两步**：先 `import`，再 `模块名.功能`。

```python
import math

print(math.sqrt(16))      # 4.0
print(math.pi)            # 3.141592653589793
print(math.floor(3.7))    # 3
```

## 二、两种导入写法

```python
# 写法一：导入整个模块
import math
print(math.sqrt(16))       # 要写模块名前缀

# 写法二：只导入某个功能
from math import sqrt
print(sqrt(16))            # 不用前缀了
```

**推荐写法一。** 因为 `sqrt(16)` 看不出它是哪来的，而 `math.sqrt(16)` 一看就知道。代码量大以后，前缀能避免很多重名混乱。

## 三、写自己的模块

**`tools.py`：**
```python
def add(a, b):
    return a + b

def is_even(n):
    return n % 2 == 0
```

**`main.py`（同一个目录下）：**
```python
import tools

print(tools.add(3, 5))          # 8
print(tools.is_even(4))         # True
```

**注意**：

- 两个文件要在**同一个目录**下
- 导入时**不写 `.py`**，写 `import tools` 不是 `import tools.py`
- `tools.py` 里直接写在顶层的代码（不在函数里的）**在 import 时就会执行**

### ⚠️ 那个「顶层代码会被执行」的坑

```python
# tools.py
def add(a, b):
    return a + b

print("tools 被加载了")      # ← 这行会在 import 时执行
```

别人 `import tools` 的时候，会莫名其妙打印一句「tools 被加载了」。

**避免方法**——把「只在直接运行时才执行」的代码放进这个判断里：

```python
if __name__ == "__main__":
    print("只有直接运行 tools.py 时才执行")
```

`__name__` 在文件被直接运行时等于 `"__main__"`，被 import 时等于模块名。**这是 Python 的常见写法**，你以后会经常见到（每个项目的入口文件底下都有）。

# 第二部分：pip —— 安装第三方库

## 一、什么是 pip

Python 官方的包管理工具，**跟 Python 一起装的**，不用单独安装。

## 二、基本用法

```bash
pip install requests          # 安装
pip install requests==2.31.0  # 装指定版本
pip uninstall requests        # 卸载
pip list                      # 看装了哪些
pip show requests             # 看某个包的详情
```

## 三、PyPI

`pip` 从 **PyPI**（Python Package Index）下载，那里有几十万个开源库。

**国内建议换镜像源**（快很多）：

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

（你已经配过了。）

# 第三部分：⚠️ 虚拟环境

## 一、为什么需要

不同项目可能需要**同一个库的不同版本**：

- A 项目要 `requests 2.20`
- B 项目要 `requests 2.31`

全装在全局 → 互相覆盖 → 两个项目都跑不起来。

**虚拟环境给每个项目一个独立的工具箱。**

## 二、创建

```bash
cd 你的项目目录
python -m venv venv
```

会生成一个 `venv` 文件夹（里面是一整套独立的 Python 环境）。

**⚠️ `venv` 文件夹不要提交到 Git**（几百兆）。你已经配好的 `.gitignore` 里就有 `venv/`。

## 三、激活

```bash
# PowerShell
venv\Scripts\activate

# cmd
venv\Scripts\activate.bat
```

成功后命令行前面出现 `(venv)`：

```
(venv) D:\code\python-practice\day08>
```

**看到 `(venv)` 就说明后面的 `pip install` 都装在这个项目里了。**

## 四、⚠️⚠️ PowerShell 的坑

**在 PowerShell 里激活，十有八九会报这个错：**

```
无法加载文件 ...\Activate.ps1，因为在此系统上禁止运行脚本。
```

**这不是你的操作有问题**，是 Windows 默认禁止运行 PowerShell 脚本（安全策略）。

**两种解决办法：**

**① 改策略（跑一次，一劳永逸）**

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

**② 或者直接用 cmd，不用 PowerShell**

cmd 走的是 `activate.bat`，不受这个限制。

## 五、退出虚拟环境

```bash
deactivate
```

## 六、怎么知道自己在不在虚拟环境里

看命令行前面的 `(venv)`。没有就是不在。

**⚠️ 常见事故**：以为自己在虚拟环境里，其实没有——结果把库装到了全局。

# 第四部分：⭐ requests —— 调接口

## 一、四步走（记住这个模式）

```python
import requests

# 第 1 步：发请求
response = requests.get("https://v1.hitokoto.cn/")

# 第 2 步：看结果
print(response.status_code)        # 200 表示成功

# 第 3 步：解析 JSON
data = response.json()

# 第 4 步：取字段
print(data["hitokoto"])
```

| 步骤 | 代码 | 干什么 |
|---|---|---|
| 1 | `requests.get(网址)` | 向服务器要数据 |
| 2 | `response.status_code` | 检查成没成 |
| 3 | `response.json()` | 把返回的 JSON 变成字典 |
| 4 | `data["字段名"]` | 从字典里取值 |

## 二、跟昨天的 JSON 完全接上

| 来源 | 解析方法 |
|---|---|
| 文件里的 JSON | `json.load(f)` |
| 网络返回的 JSON | `response.json()` |

**干的是同一件事，只是数据从哪来不同。**

## 三、状态码（记住几个常见的）

| 状态码 | 意思 |
|---|---|
| `200` | 成功 |
| `404` | 找不到（网址错了） |
| `403` | 没权限（可能要 key） |
| `500` | 对方服务器崩了 |

**写代码时应该检查一下：**

```python
if response.status_code == 200:
    data = response.json()
    print(data)
else:
    print(f"请求失败，状态码：{response.status_code}")
```

## 四、如果接口返回的是列表

```python
data = response.json()

for item in data:
    print(item["name"])
```

## 五、⚠️ 网络问题排查

调接口失败时，按这个顺序查：

| 现象 | 可能原因 |
|---|---|
| 卡住很久然后报错 | 网络不通，或需要开代理 |
| `ConnectionError` | 域名解析不了 / 网络断 |
| `Timeout` | 对方太慢，或网络慢 |
| `404` | 网址写错了 |
| `403` | 需要 API Key |

**国内调国际接口（比如 OpenAI、GitHub API）通常需要开代理。**

**测试连通性最直接的方法**：先在浏览器里打开那个网址，能看到东西就说明网络通。

## 六、给请求加超时（好习惯）

```python
response = requests.get(网址, timeout=10)
```

**不写 `timeout` 的话，网络不通时程序会**永远卡住**。** 养成加超时的习惯。

## 练习 2：探测哪个接口能通

跑下面这个脚本，看哪个接口能通（国内国外能访问的网站不同，实测最准）：

```python
import requests

candidates = [
    ("一言",   "https://v1.hitokoto.cn/"),
    ("天气",   "https://api.vvhan.com/api/weather"),
    ("国际天气", "https://wttr.in/Chengdu?format=j1"),
]

for name, url in candidates:
    try:
        r = requests.get(url, timeout=8)
        print(f"{name:8} {url}")
        print(f"         状态码 {r.status_code}")
        if r.status_code == 200:
            print(f"         返回内容前 100 字：{r.text[:100]}")
    except Exception as e:
        print(f"{name:8} 失败：{type(e).__name__}")
    print()
```

**把结果发我**，我们用通的那个继续。

# 常见报错

| 报错 | 原因 | 怎么修 |
|---|---|---|
| `ModuleNotFoundError: No module named 'requests'` | 没装，或不在虚拟环境里 | 先激活虚拟环境，再 `pip install` |
| `无法加载文件 Activate.ps1` | PowerShell 脚本策略 | `Set-ExecutionPolicy` 或用 cmd |
| `ConnectionError` / `Timeout` | 网络不通 | 检查网址、开代理、加 timeout |
| `KeyError: 'xxx'` | JSON 里没有这个字段 | 先 `print(data)` 看真实结构 |
| `JSONDecodeError` | 返回的不是 JSON | 可能是网页 HTML，`print(r.text)` 看 |
