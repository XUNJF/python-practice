# 第 42 天：流式输出（打字机效果）

**这个文件夹是什么**：笔记助手 + 流式输出。**最后一个「单 Agent」版本** —— 所有判断和回答都在一张图里。

**怎么跑**

```powershell
python -m uvicorn server:app --reload
```

浏览器开 `http://127.0.0.1:8000`

**这个文件夹需要什么**

- `key.txt`、`key_sf.txt`（或者用 `.env` 走环境变量）
- `index.json`（5.6 MB，切好的笔记块 + 向量，被 .gitignore 挡着，得自己重建）
- `Dockerfile`（可选，打包成镜像用）

**这一天改了什么**

- `rag_agent.py` 加了 `chat_stream()` —— 用 `graph.stream(stream_mode="messages")` 逐字吐，并且只转发回答节点（`answer_with_notes` / `answer_directly`）的字，把 `decide` 节点的 `search`/`chat` 过滤掉
- `server.py` 加了 `/chat/stream` —— `StreamingResponse` + NDJSON（一行一条 JSON）
- `index.html` 的 `send()` 换成「边收边渲染」：`getReader()` + `TextDecoder({stream:true})` + `buffer = lines.pop()`

**改之前的版本**：day39（只有 `/chat`，等全部生成完才返回）

**怎么验证**

点发送 → 约 2 秒后开始一个字一个字冒 → 最后贴出来源。首字时间明显早于总耗时。

**已知限制**

- 只有单 Agent，一条直线流程
- `messages` 无限增长，没有压缩
- 检索还是手算余弦（`index.json` + Python 循环）
