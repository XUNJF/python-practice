# 第 43 天：多智能体（主管 + 两个专员）

**这个文件夹是什么**：把「一个 Agent 做所有事」拆成「主管调度 + 两个专职专员」，并且把每步显示在界面上。

**怎么跑**

```powershell
python multi_agent.py          # 命令行版（底部有测试块）
python -m uvicorn server:app --reload   # 网页版
```

**这个文件夹需要什么**

- `key.txt`、`key_sf.txt`
- `index.json`（切好的笔记块 + 向量）
- `data/记忆.db`（第一次跑会自动建，SQLite 存对话）

**结构**

```
START → receive → supervisor
                     ├─ research → researcher → supervisor
                     └─ write    → writer     → END
```

- **supervisor（主管）**：看当前进度，决定下一步派谁。只回一个词 `research` 或 `write`
- **researcher（研究员）**：调 `search_notes` 翻笔记，只交资料不写答案
- **writer（撰稿人）**：拿资料 + 历史写答案
- **receive（接话）**：把这一句问题存进 `messages`，并清掉上一轮的 `notes`/`answer`/`sources`

**这一天改了什么**

- 新建 `multi_agent.py`：三节点图 + 条件边 + `SqliteSaver` 记忆
- `server.py` 换成 `stream_mode=["updates","messages"]`：`updates` 出步骤、`messages` 出正文
- `index.html` 气泡拆成三块（步骤 / 答案 / 来源），根据 `type: "step"` 追加步骤行

**怎么验证**

问「RAG 是什么」→ 界面上先出现三行步骤（主管派研究员 → 研究员查完 → 主管派撰稿人），然后逐字出答案。再问「我是谁」→ 能答出上轮说的名字。

**已知限制**

- `messages` 无限增长（这个问题 day44+45 才解决）
- 只有两个专员，主管的选择空间小
