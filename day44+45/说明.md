# 第 44 + 45 天：计算员 + 历史压缩

**这个文件夹是什么**：给多智能体加了两个能力 —— 一个会算数的专员，和一个「历史太长就压缩」的节点。

**⚠️ 注意：这个文件夹没有 `index.html`。** 网页版跑不了，只能用命令行。要网页版请用 **day46**（或者把 day43 的 index.html 拷过来）。

**怎么跑**

```powershell
python multi_agent.py      # 底部有测试块，跑四句话
python safe_calc.py        # 单独测安全求值器
```

**这个文件夹需要什么**

- `key.txt`、`key_sf.txt`
- `index.json`
- `data/记忆.db`（自动建）

**结构（比 day43 多了两个节点）**

```
START → compress → receive → supervisor
                                ├─ research → researcher → supervisor
                                ├─ calc     → calculator → supervisor
                                └─ write    → writer     → END
```

**第 44 天：计算员（`safe_calc.py` + `calculator` 节点）**

- 模型负责把中文题**翻译成算式**（「8472加3951再乘27」→ `(8472+3951)*27`），Python 负责**算**
- `safe_eval()` 用 `ast` 做**白名单求值**：只放行 `Constant` / `BinOp` / `UnaryOp` 三种节点，其他一律 `raise`
- 挡得住 `__import__('os').system(...)`、`open()`、`[1,2,3]`、`1 if True else 2`
- **不要用 `eval()`** —— 它能把任意字符串当代码执行

**第 45 天：历史压缩（`compress` 节点）**

- `MAX_MESSAGES = 4`、`KEEP_RECENT = 2`（演示值，真用可以 20 / 6）
- 超过阈值 → 把旧的压成摘要存进 `summary` 字段 → 用 `RemoveMessage(id=m.id)` 删掉原文
- `compress` 必须在 `receive` **前面**，否则会把刚问的问题也压掉
- `supervisor` 和 `writer` 都要把 `summary` 拼进提示词

**怎么验证**

```
我是小明                  → 直接答，不查资料
我是谁？                  → 靠摘要答出「小明」（历史原文早被压掉了）
8472加3951再乘27减1364    → 计算结果：(8472+3951)*27-1364 = 334057
RAG 是什么？              → 派研究员，有资料
```

**已知限制**

- 摘要会**丢信息**：实测同一输入跑 6 次，旧提示词丢了 1 次「我是小明」。**靠把「用户的姓名/身份/偏好/习惯」写进摘要提示词的「必须保留」项才压下来**
- 摘要本身会累积变长（69 → 125 → 288 字），长期要二次压缩
- 检索还是手算余弦（day46 才换 Chroma）
