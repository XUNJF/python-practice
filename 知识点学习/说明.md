# 知识点学习

**这个文件夹是干什么的**：学新东西的地方。每个知识点单独一个 `.py`，随便试、试坏也不影响项目。

**学习 → 进项目 的流程**

```
① 在这里写 xxx_learn.py，把新东西玩通
② 确认懂了，再回 day46 改真正的项目代码
③ 回 day46 改完，跑四题回归，确认没搞坏
```

**项目本体在** `D:\code\python-practice\day46`（笔记助手，多智能体 + Chroma）

---

## 怎么跑这里的脚本

**用 day46 的 venv**（里面已经装了 langgraph / langchain-deepseek / chromadb / fastapi / requests）

```powershell
cd D:\code\python-practice\day46
.\venv\Scripts\Activate.ps1

cd D:\code\python-practice\知识点学习
python xxx_learn.py
```

**激活之后 `python` 就指向 day46 那个解释器，跟你在哪个目录无关。** 验证：

```powershell
where.exe python
```

应该只输出一行 `...\day46\venv\Scripts\python.exe`

**什么时候才需要自己建 venv**：只有当实验要装的包会破坏项目环境（比如要求某个库的大版本升级）时。那时候再建，不用提前。

---

## 想用项目里的代码（`rag_agent` / `search_chroma` 等）

**脚本开头加一行：**

```python
import sys
sys.path.insert(0, r"D:\code\python-practice\day46")

import search_chroma
```

**不加会报 `ModuleNotFoundError`** —— Python 只在自己所在目录和几个固定地方找模块，不会自动去隔壁文件夹。

**另一种做法**：把实验脚本直接放进 `day46` 里，就自动能 import 了（但会让项目文件夹变乱，看你取舍）。
